# Task 3 - Campus Library Search Screen

## Aim

Build a resizable Swing library search interface using nested layout managers.

## Run

```powershell
javac -d Task03\out Task03\src\*.java
java -cp Task03\out Main
```

## Sample execution

Enter `Java` and select **Computer Science**, then click **Search**. Matching
books appear in the scrollable results area. **Prev**, **Next**, and
**Reserve** update the status label.

## Verification

Working sources compile with Java 17. Resize behavior and layout analysis are
documented in `notes.md`.
