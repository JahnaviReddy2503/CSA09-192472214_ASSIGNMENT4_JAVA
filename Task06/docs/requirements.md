# Stage 1 requirements

R1 Users can enter student ID, name, email, department, and event. R2 empty
fields and malformed email are rejected. R3 duplicate student/event pairs are
rejected by service and database UNIQUE constraint. R4 registrations appear in
a paged JTable. R5 event filtering and CSV export are available. R6 database
work runs in SwingWorker. R7 File Export/Exit, View Refresh, and Help About
menus exist.
